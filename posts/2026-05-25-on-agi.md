# On AGI

This week's sharing is about OpenClaw, and also a realization of mine.

I'm sure you've all heard about OpenClaw by now, some of you may already have your own claw running somewhere. To be honest, I stayed away from it for a long time, because I just didn't see the point. If I want to get something done, I'll just ask Codex, and if I'm feeling adventurous that day, I'll go with yolo mode.

Until recently. One of my vibe-code hobby projects has been web enhancement Greasemonkey scripts, to tailor the web surfing experience to my own taste. One thing that hasn't worked well is the feedback loop. Due to iOS limitations, the development flow basically involves me asking an LLM to work on something, then manually pulling the change, testing it out, and giving feedback. Because of Safari's quirks, a lot of times we have to go through multiple rounds of back-and-forth with the LLM.

I've been thinking about how to improve this flow. Two weeks ago, Codex shipped with the computer use feature, that might be what I've been waiting for, so I tried it out on day one with my personal ChatGPT account. It's a neat feature, but still doesn't work that well, probably mainly because OpenAI is still holding back on the permission controls. That's when I thought, why not go all the way and give OpenClaw a try. So I set up a VM sandbox, hooked it up with DeepSeek v4, granted it every single permission it needs, woke it up, and asked it to get to work.

The outcome was pretty impressive, I have to say. With not a lot of instructions, it figured out how to hack the iPhone simulator, built wBlock (the app I use to load the custom user scripts) into the simulator so it could test the code end-to-end, and only buzze me when it was done for real. It showcases that agentic autonomy can unleash even more LLM potential.

That said, some scripts still aren't perfect one way or another... My wife had a remark for me, quote: "deep down, you don't want to leave your computer and go out." Of course I'm not crazy enough to contradict her, but when she said that, I did turn my back, roll my eyes a little, what do you even mean? I'm here, aren't I? And I do enjoy the trip. What does it even matter what I want deep down, I've been a good team player and have been doing exactly what I'm told, isn't that enough already?

That's when it hit me. Ahhh. If my claw doesn't have the need, the craving, the desire for the best web surfing experience, how could it possibly create output that truly satisfies me? My claw would never become the perfect claw I wish it to become. Which also means the AGI we saw in the movies may never come. We, the human race, are safe after all. What a relief.
